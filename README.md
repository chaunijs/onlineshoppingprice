# 🛒 Online Shopping Price Tracker - Developer Documentation

> Automated web scraping pipeline for tracking product pricing and promotions across major online retailers.

## 📝 Overview

This project is a Python-based web scraping architecture designed to extract, transform, and store product pricing and promotional data from various e-commerce platforms. 

Because each retailer employs different frontend frameworks and anti-bot mechanisms (such as Cloudflare), the system relies on headless browser automation via **Playwright** and **Patchright** (to bypass advanced bot detection). The pipeline is fully automated using **GitHub Actions**, triggering sequential scraper executions and archiving the resulting datasets as workflow artifacts.

---

## 🏗️ System Architecture & Components

The repository is modularized into several key components to separate testing, execution, and automation logic.

### 1. Orchestrator (`orchestrator.py`)
This is the central entry point for the production run. 
* **Sequential Execution:** It systematically triggers individual scraping modules located in the `py/` directory.
* **Fault Tolerance:** If one retailer's scraper fails (e.g., due to a layout change or CAPTCHA block), the orchestrator catches the exception, logs the error, and gracefully continues to the next retailer to ensure partial data delivery.

### 2. Retailer Scraping Modules (`py/*_scraper.py`)
Each file (e.g., `makro_scraper.py`, `tops_scraper.py`) contains the site-specific extraction logic.
* **Browser Automation:** Utilizes Patchright/Playwright for reliable rendering of Single Page Applications (SPAs) and handling dynamic DOM elements.
* **Data Transformation:** Extracted raw data is processed into **Polars DataFrames** for highly performant, parallelized data manipulation before export.
* **Schema Design:** To maintain structural integrity during DataFrame operations and downstream ingestion, complex or nested scraping conditions (such as specific "1 Free 1" or bulk discount rules) are serialized and stored as **JSON strings** rather than nested column schemas.

### 3. Output Directory (`py/output/`)
* Acts as the local data sink during execution. All resulting `.xlsx` or `.csv` files generated by the scraping modules are dumped here before being archived by the CI/CD pipeline. The directory is ignored in Git (`.gitignore`) to prevent bloating the repository with data files.

### 4. Sandbox Environment (`notebook_ipynb/`)
* Contains Jupyter Notebooks used strictly for R&D. 
* Developers use this environment to reverse-engineer API endpoints, test CSS/XPath selectors, and debug Cloudflare bypass strategies (e.g., `big_C_cloudflare.ipynb`) before refactoring the logic into the production `py/` modules.

## ⚙️ CI/CD Pipeline (`pipeline.yml`)

The project utilizes GitHub Actions to completely automate the data collection process without requiring a dedicated server. 

### Pipeline Workflow
1. **Trigger:** Runs automatically via a CRON schedule on Mondays, Wednesdays, and Fridays at 09:00 UTC. It can also be triggered manually via `workflow_dispatch`.
2. **Environment Setup:** Spins up an `ubuntu-latest` runner and provisions Python 3.11.
3. **System Dependencies:** Installs `tesseract-ocr` and `tesseract-ocr-tha` at the OS level. This is critical for modules (like Big C) that require optical character recognition to parse text from rendered images or bypass visual verifications.
4. **Python & Browser Packages:** Installs standard dependencies from `requirements.txt`, followed by downloading the necessary Chromium binaries and system dependencies required by Playwright and Patchright.
5. **Execution:** Runs `python orchestrator.py`.
6. **Artifact Archival:** Collects everything generated in `py/output/` and zips it into a downloadable GitHub Artifact named `scraping-pipeline-outputs`. 
7. **Storage Optimization:** Artifacts are configured with a strict `retention-days: 7` policy to manage GitHub storage quotas efficiently.

## 🚀 Local Development Setup

To run or debug the scrapers locally:

```bash
# 1. Clone the repository
git clone [https://github.com/chaunijs/onlineshoppingprice.git](https://github.com/chaunijs/onlineshoppingprice.git)
cd onlineshoppingprice

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Install Playwright/Patchright browsers and OS dependencies
playwright install chromium
playwright install-deps
patchright install chromium
patchright install-deps

# 4. Execute the orchestrator
python orchestrator.py
